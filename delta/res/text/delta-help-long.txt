Basic Syntax:

    delta-cli ( -h | --help | -help | -? ) [--verbose]
    delta-cli ( -v | --version | -version )
    delta-cli delta [<delta-options...>] [--] <srcFilePath> <targetFilePath>
    delta-cli reconstruct [<recon-options...>] [--] <srcFilePath> <deltaFilePath>

Commands:

    delta-cli ( -h | --help | -help | -? ) [--verbose]

        Prints this help message and exits. 
        
        If any of these flags are present at all (even in some other command), 
        only this help message will be printed, and any other command, flag, or 
        argument will be ignored. This can also occur if a command is 
        unrecognized (e.g. "delta-cli garbage").

    delta-cli ( -v | --version | -version )

        Prints the program name, author, license and version, and exits. 
        Equivalent output information is visible at the top of this help message.

        If any of these flags are present at all (even in some other command), 
        only the version message will be printed, and any other command, flag, or
        argument will be ignored, unless one of them is a help flag, in which 
        the full help message will be shown instead (what you see right now).

    delta-cli delta ... <srcfilePath> <targetFilePath>

        Computes the delta file from <srcFilePath> to <targetFilePath>. In 
        other words, this generates the patch needed to reconstruct the target 
        file given only the delta file and the src file. Neither input is modified.
        
        By default, the delta file is outputted into the current working 
        directory with the target  file's name with a ".delta" suffix, which can 
        be overridden with the either the "-o" or "--output" flags. If the 
        destination already exists (default dest or user-provided), the program 
        exits with an error (code -10), unless the --force-destination-delete flag
        is present, in which it will be deleted.

    delta-cli reconstruct ... <srcFilePath> <deltaFilePath>

        Applies the given delta file to the src file, creating the original target
        file. In other words, this is the inverse of "delta-cli delta", as it gets 
        the target file input given the src file and such command's output. This 
        modifies neither the src file nor the delta file.
        
        By default, the target file is outputted into the current working 
        directory with the delta file's name minus the ".delta" suffix, which can 
        be overridden with the either the "-o" or "--output" flags. If the 
        destination already exists (default dest or user-provided), the program 
        exits with an error (code -11), unless the --force-destination-delete flag
        is present, in which it will be deleted.

Flags:

    --              Separates options from command arguments

    -?              Same as -h

    --error         Same as --quiet (see below)

    --force-destination-delete
                    Allows the output of delta or reconstruct to delete a
                    conflicting file which has the same name as the output.
                    This does NOT prompt before deleting the conflicting file,
                    to do that, use -p or --prompt. If prompt is mixed with
                    this flag, prompt takes precedent.

    -h --help -help
                    Prints this help message and exits. Using the --verbose 
                    flag greatly increases the detail of the message (like 
                    you are seeing now).

    --ignore-hash   Prevents hashing during delta generation, and ignores hash
                    differences when reconstructing

    -o <outputFilePath> --output <outputFilePath>
                    The file to write deltas and reconstructed targets to.
                    By default, a file that conflicts with the output will cause
                    the program to exit with an error, unless either the
                    --prompt, -p, or --force-destination-delete flag is present.

    --preserve      Prevents an output file from being deleted if there is any 
                    content in it. By default, files were in the middle of a write
                    when an error occurred will be deleted; this flag prevents that.

    -p --prompt     Prompts before allowing the output of delta or reconstruct to 
                    delete a conflicting file which has the same name as the 
                    output. This flag takes precedent over 
                    --force-destination-delete if both are present.

    --quiet         Only displays errors and standard input prompt messages.

    --silent        Suppress all standard output and standard input, including 
                    errors. If both this flag and --prompt (or -p) are present,
                    all --prompt behavior is ignored; it is as though --prompt
                    was never passed.

    -v --version -version
                    Displays the program name (delta-cli), version, author, date,
                    and license. 

    --verbose       For --help, increases message length. For delta or reconstruct,
                    increases amount of info logged to standard output.

Troubleshooting:

    - Ensure the %DELTA_CLI_HOME% is set to the directory with README.md at 
    its top. %DELTA_CLI_HOME%/res/text/delta-help-long.txt should resolve to this 
    exact file.

    - The first argument to this program must always be a command described in the 
    above "Commands" section; otherwise, this help message will be printed. 

    - COMMANDS AND FLAGS ARE CASE-SENSITIVE!

    - Try wrapping file paths with double quotes
